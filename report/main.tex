\begin{abstract}
\noindent\textbf{Abstrak.}
Laporan ini menyajikan implementasi \emph{from-scratch} Transformer pada tiga domain: klasifikasi sentimen teks (IMDb), klasifikasi gambar (CIFAR-10) dengan Vision Transformer (ViT), dan tugas non-klasifikasi berupa \emph{Single Image Super-Resolution} memakai Swin2SR \emph{pretrained}. Pada IMDb, Transformer (87{,}51\%) hanya unggul 0{,}48~pp atas MLP; pada CIFAR-10, SmallResNet (76{,}17\%) mengungguli ViT (66{,}03\%) sebesar 9{,}5~pp dengan $\sim$3$\times$ parameter lebih sedikit. Modifikasi pada Swin2SR berupa \emph{tiled inference} dengan \emph{feathered blending} memungkinkan inferensi pada gambar berukuran sembarang tanpa OOM (selisih piksel $\approx 0{,}05\%$). Hasil menegaskan bahwa \emph{inductive bias} konvolusional masih relevan pada dataset kecil. \\
\textit{Kata kunci---}\,Transformer, ViT, IMDb, CIFAR-10, Swin2SR, \emph{Tiled Inference}.
\end{abstract}

\section{Pendahuluan}
% ════════════════════════════════════════════════════════════════════

Arsitektur Transformer \cite{vaswani2017} kini menjadi tulang punggung model modern di NLP, \emph{computer vision}, dan \emph{multimodal learning} berkat mekanisme \emph{self-attention} yang menangkap dependensi jarak jauh tanpa rekurensi atau lokalitas konvolusi. Namun, ketika data terbatas atau tugas didominasi pola lokal, model dengan \emph{inductive bias} sesuai (CNN, LSTM) sering kompetitif atau bahkan unggul \cite{dosovitskiy2021}.

Laporan ini mendokumentasikan eksperimen komparatif pada tiga domain: (i) klasifikasi teks Transformer vs. MLP/CNN-1D \cite{kim2014}/RNN pada IMDb 50K \cite{maas2011}; (ii) klasifikasi gambar ViT \cite{dosovitskiy2021} vs. MLP/SimpleCNN/SmallResNet \cite{he2016} pada CIFAR-10 \cite{krizhevsky2009}; (iii) modifikasi Swin2SR \cite{conde2022,liang2021} untuk \emph{Single Image Super-Resolution}. Tujuan utama: memahami implementasi, mengukur \emph{trade-off}, dan memodifikasi kode \emph{open-source} nyata---bukan mengejar akurasi tertinggi.

\section{Arsitektur Model}
% ════════════════════════════════════════════════════════════════════

Seluruh blok Transformer/ViT ditulis \emph{dari nol} di PyTorch (tanpa \texttt{nn.TransformerEncoder} bawaan).

\textbf{Model Teks} (input \texttt{(B,T)} $\to$ logits \texttt{(B,2)}): (i)~\emph{TransformerClassifier}---Embedding + sinusoidal PE + 2$\times$ EncoderBlock (MHA + FFN + LN) + \emph{mean-pool} (abaikan padding) + Linear; $d_{\text{model}}{=}128$, $h{=}4$, $L{=}2$, $d_{\text{ff}}{=}256$, dropout~0{,}1. (ii)~\emph{MLPClassifier}: Embedding + mean-pool + FC$[256,128]$ + Linear. (iii)~\emph{CNN1D} \cite{kim2014}: Embedding + parallel Conv1d kernel $\{2,3,4\}$ + max-over-time + Linear. (iv)~\emph{RNN}: Embedding + 2-layer biRNN + last hidden + Linear.

\textbf{Model Gambar}: (i)~\emph{ViT}---PatchEmbed (Conv2d~$4{\times}4$, stride~4 $\Rightarrow$~64 patch) + \texttt{[CLS]} + learnable PE + 6$\times$ EncoderBlock + LN + Linear pada \texttt{[CLS]}; $d_{\text{model}}{=}192$, $h{=}6$, $L{=}6$. (ii)~\emph{ImageMLP}: Flatten + FC$[512,256]$. (iii)~\emph{SimpleCNN}: 3 blok Conv-BN-ReLU-Pool (32$\to$64$\to$128) + GAP, hanya 95k parameter. (iv)~\emph{SmallResNet}: stem + 3 stage (6 BasicBlock).

\textbf{Training}: Adam (lr=$10^{-3}$, wd=$10^{-5}$), CrossEntropyLoss, 10 epoch, batch 64 (teks)/128 (gambar), seed~42. Hardware: NVIDIA RTX 5060 Ti, 17{,}1~GB VRAM, PyTorch 2.11 + CUDA 13.

\section{Swin2SR Super-Resolution (Non-Klasifikasi)}
% ════════════════════════════════════════════════════════════════════

Repository \texttt{mv-lab/swin2sr}\footnote{\url{https://github.com/mv-lab/swin2sr}} \cite{conde2022,liang2021} memberi \emph{Single Image Super-Resolution} (SISR); output berupa tensor RGB beresolusi penuh, bukan probabilitas kelas. Digunakan checkpoint \texttt{caidas/swin2SR-classical-sr-x2-64} (12{,}09\,M parameter, skala 2$\times$) dalam mode \emph{inference-only}. Gambar~\ref{fig:sr} membandingkan LR asli, \emph{bicubic}, dan Swin2SR; Swin2SR memberi tepi tajam dan detail lokal lebih kaya.

\textbf{Modifikasi---\emph{Tiled Inference} dengan \emph{Feathered Blending}.} Swin2SR dilatih pada \emph{window} $64\times64$; pada gambar besar, kompleksitas \emph{self-attention} $O(N^2)$ memicu OOM. Fungsi \texttt{tiled\_super\_resolution()} memecah gambar menjadi tile $64\times64$ dengan \emph{overlap} 8 piksel, menjalankan inferensi per tile, lalu menggabung output dengan \emph{triangular feather window} agar tidak ada \emph{seam}; fallback ke inferensi biasa untuk gambar~$\leq$~tile. \textbf{Validasi}: pada $48{\times}48$, selisih piksel \emph{nol} (transparent); pada $128{\times}128$, rata-rata selisih $0{,}139/255 \approx 0{,}05\%$ (visual identik, Gambar~\ref{fig:sr}-bawah), waktu eksekusi 0{,}39\,s (4 tile).

\begin{lstlisting}[basicstyle=\ttfamily\scriptsize]
def tiled_super_resolution(pil_img, model, processor,
                           tile=64, overlap=8, scale=2):
    W, H = pil_img.size
    if W <= tile and H <= tile:
        return swin2sr_inference(pil_img, model, processor)
    ramp = np.linspace(0, 1, tile*scale, dtype=np.float32)
    win  = np.minimum(ramp, ramp[::-1])
    win2d = (win[:,None]*win[None,:])[...,None]
    # iterate tiles with stride = tile - overlap ...
\end{lstlisting}

\section{Analisis dan Diskusi}
% ════════════════════════════════════════════════════════════════════

\textbf{Model terakurat \& tercepat.} Pada teks, Transformer (87{,}51\%) hanya unggul 0{,}48~pp atas MLP yang 9$\times$ lebih cepat (13{,}9~s vs 120{,}7~s). Pada vision, SmallResNet (76{,}17\%) mengungguli ViT 9{,}5~pp dengan parameter $\sim$3$\times$ lebih sedikit; SimpleCNN paling efisien (95k parameter, 0{,}6151).

\textbf{Apakah Transformer selalu lebih baik?} Tidak. CNN unggul pada gambar kecil karena \emph{inductive bias} berupa \emph{translation equivariance} dan \emph{locality} cocok dengan struktur gambar dan 50k sampel CIFAR-10. LSTM/CNN-1D tetap relevan untuk teks pendek: IMDb didominasi kata kunci lokal (\emph{``amazing'', ``boring''}) yang ditangkap kernel n-gram CNN-1D dengan akurasi 86{,}82\% (hanya 0{,}7~pp di bawah Transformer) namun 5$\times$ lebih cepat.

\textbf{Kelemahan Transformer pada data kecil.} Banyak parameter dan sedikit prior memicu overfitting: pada Transformer/IMDb, \emph{train acc} 97{,}96\% vs \emph{test acc} 87{,}51\% (gap 10~pp). Perlu regularisasi kuat atau \emph{pretraining} masif.

\textbf{Pengaruh hiperparameter struktural.} \emph{Patch size} kecil ($p{=}2$) terbaik tapi 5$\times$ lebih mahal; $p{=}16$ menyisakan 4 patch dan akurasi jatuh ke 31\%. \emph{Sequence length} 64$\to$256 menambah akurasi 8~pp; 256$\to$512 hanya 0{,}5~pp karena hanya $\sim$10\% review $>$256 kata.

\textbf{Swin2SR.} Input: gambar LR; output: gambar HR 2$\times$---bukan klasifikasi (output piksel, bukan label diskrit). Modifikasi \emph{tiled inference} memungkinkan SR pada gambar berukuran sembarang tanpa OOM dengan output praktis identik (selisih $\sim$0{,}05\%).

% ════════════════════════════════════════════════════════════════════
\section{Kesimpulan}
% ════════════════════════════════════════════════════════════════════

Transformer tidak selalu unggul: pada IMDb hanya 0{,}5~pp di atas MLP, pada CIFAR-10 kalah 9{,}5~pp dari SmallResNet (parameter $\sim$3$\times$ lebih sedikit). \emph{Inductive bias} konvolusional dan rekuren tetap relevan pada dataset kecil dan teks pendek. Hiperparameter struktural (\emph{patch size}, \emph{sequence length}) sangat menentukan---\emph{sweet spot} bergantung karakteristik data. Untuk SISR, Swin2SR \emph{state-of-the-art}, dan modifikasi \emph{tiled inference} membuatnya praktis untuk gambar berukuran sembarang dengan output praktis identik. Kode lengkap tersedia di \texttt{main.py}, \texttt{transformer\_assignment.ipynb}, modul \texttt{models/} dan \texttt{utils/}; eksekusi penuh $\approx 22$ menit pada RTX 5060 Ti.
